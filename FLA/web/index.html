        AutomataForge — Advanced Finite Automata Studio

        1. Editor — Manage states, alphabet, and transitions. Double-click the canvas to quickly add a new state; double-click a state to toggle accepting.
        2. Regex ➔ NFA — Enter any regular expression (e.g. (a|b)*abb, (0|1)*00) to generate an ε-NFA using Thompson's construction with automated layered layout.
        3. Simulation — Step through strings symbol-by-symbol, forward, backward, or auto-play.
        4. Transformations — NFA ➔ DFA (subset construction table), DFA Minimization (Moore partition refinement), Automaton ➔ Regex (GNFA state elimination), and DFA Complementation.
        5. Batch & Words — Generate the first N shortlex words accepted by the language; run batch test suites with visual pass/fail indicators.
        6. Equivalence — Determine if two automata recognize the exact same language (L1 == L2) or find shortest counterexample strings.
        7. Interoperability & Export — Export to PNG, SVG, Graphviz DOT (.dot), Mermaid (.mmd), LaTeX TikZ (.tex), JFLAP XML (.jff), and printable PDF reports. Import both .afjson and JFLAP .jff files!
        8. Random Gen — Generate a random DFA or NFA with a configurable number of states, alphabet size, transition density and accept ratio; NFAs may include ε-transitions.
        9. Distribution — Inspect the word-length profile of the language: which string lengths are accepted, computed by dynamic programming over state sets.

        Keyboard shortcuts: Ctrl+Z undo · Ctrl+Y redo · Enter simulates · ← → step through simulation.
